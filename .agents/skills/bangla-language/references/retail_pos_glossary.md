# Bangladeshi Retail & POS Bilingual Glossary

This reference dictionary provides standardized commercial, accounting, inventory, and point-of-sale translations commonly understood in Bangladesh. Use these terms when localizing POS apps, receipts, invoices, stock managers, and customer ledgers.

---

## 1. Billing & Receipt Headers / Actions

| English Term | Recommended Bangla | Common Spoken Variant | Awkward / Archaic to Avoid |
| :--- | :--- | :--- | :--- |
| **Invoice / Bill** | **চালান / বিল** | ক্যাশ মেমো / রশিদ | চালানপত্র, পণ্য বিবরণী |
| **Invoice No / Bill No** | **চালান নং / বিল নং** | রশিদ নং / মেমো নং | চালান ক্রমিক সংখ্যা |
| **Date & Time** | **তারিখ ও সময়** | তারিখ | কাল ও তারিখ |
| **Cashier / Operator** | **ক্যাশিয়ার** | বিক্রেতা | কোষাধ্যক্ষ, হিসাবরক্ষক |
| **Terminal / Counter** | **কাউন্টার / টার্মিনাল** | ক্যাশ কাউন্টার | প্রান্তিক কেন্দ্র |
| **Customer** | **ক্রেতা / কাস্টমার** | গ্রাহক | খরিদ্দার, গ্রহীতা |
| **Phone Number** | **মোবাইল / ফোন** | মোবাইল নম্বর | দূরালাপনী নম্বর |
| **Address** | **ঠিকানা** | ঠিকানা | বাসস্থান |

## 2. Financial Totals & Calculations

| English Term | Recommended Bangla | Common Spoken Variant | Awkward / Archaic to Avoid |
| :--- | :--- | :--- | :--- |
| **Subtotal** | **উপমোট** | সাবটোটাল | মধ্যবর্তী যোগফল, উপ-মোট |
| **Total / Grand Total** | **সর্বমোট** | মোট টাকা / মোট | চূড়ান্ত মোট অঙ্ক |
| **Discount** | **ছাড়** | ডিসকাউন্ট | বাট্টা, মূল্য হ্রাস |
| **Special Discount** | **বিশেষ ছাড়** | স্পেশাল ডিসকাউন্ট | বিশেষ বাট্টা |
| **VAT / Tax** | **ভ্যাট / ট্যাক্স** | সরকারি ভ্যাট | কর, মূল্য সংযোজন কর (বড় লেখা) |
| **Delivery Charge** | **ডেলিভারি চার্জ** | পৌঁছানোর খরচ | পরিবহন মাশুল |
| **Service Charge** | **সার্ভিস চার্জ** | সেবা খরচ | পরিষেবা মাশুল |
| **Rounding Off** | **রাউন্ডিং** | ভাংতি সমন্বয় | গোলকরণ |
| **Net Amount** | **প্রদেয় মোট / মোট প্রদেয়** | চূড়ান্ত বিল | নীট মূল্য |

| **Stock / In Stock** | **মজুদ / স্টকে আছে** | মালামাল আছে | ভাণ্ডার |
| **Out of Stock** | **স্টক শেষ / মজুদ নেই** | মাল নেই | ভাণ্ডার শূন্য |
| **Low Stock Alert** | **কম মজুদের সতর্কতা** | মাল কমে গেছে | স্বল্প মজুদ সঙ্কেত |
| **Barcode / SKU** | **বারকোড / কোড** | কোড নং | দণ্ড সঙ্কেত |
| **Category** | **ক্যাটাগরি / বিভাগ** | শ্রেণি | প্রকারভেদ |
