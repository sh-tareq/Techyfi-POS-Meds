# Project Rules & Customizations

1. **APK File Deliverable Convention**:
   - Save built APK files ONLY in the project directory (`/Users/shahidulhaque/App Dev/Techyfi POS Gemini/`).
   - For each change/build, increment the APK version sequentially: `Techyfi-POS-Final-V1.apk`, `Techyfi-POS-Final-V2.apk`, `Techyfi-POS-Final-V3.apk`, and so on.
   - Do NOT save APK files to Desktop or other folders outside the project directory unless explicitly asked.

2. **UI/UX Design Standards**:
   - Follow global UI/UX skills (`ui-ux-design`, `android-ui-ux`, `ui-ux-audit`) for all Jetpack Compose layout, Material 3 design, touch target sizing (>= 48dp), accessibility, animation, and ergonomic mobile POS interface design.

3. **Bangla Language & Localization Standards**:
   - Follow the `bangla-language` skill for all Bengali translations, natural Bangladeshi retail/commercial phrasing, thermal receipt formatting, typography, and preserving untranslated technical/dynamic data.
