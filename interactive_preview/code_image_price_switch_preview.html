🚀 Suggested High-Value Improvements for Your Approval

These enhancements can be bundled together cleanly without adding clutter or complicating the workflow:

🏷️
1. Dual Price Display Mode (MRP & Special Offer)
RECOMMENDED
Allows printing both MRP and the Selling/Discounted price side-by-side (e.g. MRP: ৳85 | Offer: ৳70). In Bangladeshi retail, this builds consumer trust and highlights store discounts immediately.
⚡
2. Quick In-Dialog Price Setting for Missing Tiers
ERGONOMICS
If a product has mrpPrice = 0.0 or wholesalePrice = 0.0, the chip displays (৳0 - Not Set) with a pencil icon. Clicking it opens a quick inline sheet to set the price without having to exit to the Edit Product screen.
🇧🇩
3. Bangla Numerals & Prefix Toggle for Localized Receipts
LOCALIZATION
Follows the bangla-language standard: allows toggling between English digits (Price: ৳70) and localized Bangla numerals (মূল্য: ৳৭০, এমআরপি: ৳৮৫, পাইকারি: ৳৬২) based on the merchant's customer base.
📦
4. Batch Code Labels Price Tier Integration
BULK PRINT
Extends the same Price Tier selection into the Batch Print Labels dialog. When printing a PDF sheet of 50 or 100 stickers for wholesale orders or shelf replenishment, merchants can choose Selling, MRP, or Wholesale for the entire run.
⚖️
5. Persistent User Preference Remembering
SMART DEFAULTS
Saves the selected price tier in SharedPreferences("product_code_image_settings") as price_tier_mode ("SELLING", "MRP", "WHOLESALE", "DUAL") so the user's preferred printing mode remains active across sessions.
